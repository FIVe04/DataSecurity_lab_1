# Лабораторная работа 1 по дисциплине "Защита данных"
#### тема: "Разработка программы  разграничения полномочий пользователей на основе парольной аутентификации"

### Требования к паролю: 
15.	Наличие латинских букв, символов кириллицы и знаков арифметических операций.

### Примечания
- admin при первом запуске создается с пустым паролем, нужно зарегистрироваться
- когда admin добавляет пользователя, он тоже создается с пустым паролем и необходимо зарегистрироваться
- данные хранятся в локальной базе данных в захешированном виде
